# Reference indexes

Start here for maintained evidence records and browsing views. Records migrated on 2026-11-01
now use the organized locations below. Phase 4 integration validation was accepted on 2026-11-01;
the [closeout record](../../docs/implementation/projects/reference-index-reorganization/reference-index-reorganization-closeout.md) distinguishes
completed work from pending final acceptance/publication.

| Collection | Contents |
| --- | --- |
| [AnimeHistory](animehistory/README.md) | Shared gallery locators, annotations, timing registers and episode-review workflow |
| [Website context](context/README.md) | Shared subjects, captured-source identities, condensed claims and typed links |
| [Sources](sources/README.md) | Local source inventory and external-source register |
| [Settei](settei/README.md) | Screening register, collection batches and focused production-sheet reviews |
| [Episodes](episodes/README.md) | Per-episode preparation, alignment, survey and targeted evidence |
| [Performance](performance/README.md) | Curated metrics, subtitle audit and extraction provenance |
| [Comparisons](comparisons/README.md) | Reconciliations spanning episodes and sources |
| [Supplied references](supplied-references/README.md) | Supplied/third-party notes with their evidence limits |

CSV registers own maintained tabular data; XLSX files are ignored browsing projections. Source
media, full subtitles, frames, contact sheets, caches and RARs retain their existing local-only
storage. A navigation page does not promote an observation or mark an episode reviewed.

See the [project tool directory](../../tools/README.md) for supported entry points and the
[reorganization plan](../../docs/implementation/projects/reference-index-reorganization/reference-index-reorganization-plan.md) for migration status.

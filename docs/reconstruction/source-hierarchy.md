# Source hierarchy

Use anime scenes for directly observed behavior and appearance; production drawings for mechanical and spatial intent; official supplements for corroboration. This is a contextual hierarchy, not a rule to erase disagreements between animation and drawings.

Local sources:

- SET-001 through SET-221: _source_settei/img001.jpg through img221.jpg.
- EP-01 through EP-26: numbered MKV filenames; EP-PILOT: separate S3 pilot.
- SFV: supplied checksum list, not visual evidence or proof of provenance.
- BRIEF: original user handover; planning input, not an independently verified source.

Inventory records filenames, byte sizes, SHA-256 digests, and image dimensions. The 221 scans are a presumed production-reference collection; approval/origin is not independently established.

Do not assume img023–img048 is exhaustive. Screen every image. Do not assume anime geometry is internally consistent.

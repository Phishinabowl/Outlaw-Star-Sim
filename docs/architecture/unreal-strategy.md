# Unreal strategy

Preferred stack: Unreal Engine 5, C++ foundations, Blueprints for editor-facing configuration, content hookup, animation/VFX/audio events, and light behavior; Blender for reconstruction; Git and later Git LFS for owned assets.

Core simulation and gameplay remain inspectable, testable, and diffable C++. Blueprints compose reusable foundations. Avoid monolithic Blueprint logic. Exact engine version, project/module layout, serialization, and networking policy are undecided.

No Unreal project is created in Phase 0.

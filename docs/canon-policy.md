# Canon and evidence policy

| Category | Meaning |
|---|---|
| A — CANON_DIRECT | Directly visible or stated in the anime |
| B — PRODUCTION_CANON | Approved production/settei/final mechanical designs |
| C — OFFICIAL_SUPPLEMENTAL | Official or licensed reference material |
| D — STRONG_INFERENCE | Required by multiple canonical observations |
| E — DESIGN_EXTRAPOLATION | Original design for spatial/mechanical coherence |
| F — GAMEPLAY_ADAPTATION | Intentional usability, gameplay, or technical expansion |

D/E/F must never be presented as canon. Classification and verification status are separate: an unreviewed brief claim is not verified A/B/C evidence. Collection provenance/approval status also needs confirmation before scans are conclusively treated as production canon.

Each record should carry source ID, filename, episode/timestamp or visible sheet number, observation, category, review status, reconstruction relevance, and unresolved questions. Filename numbers are collection IDs, not assumed printed production sheet numbers.

Keep original Japanese transcription separate from translation; record uncertainty. Contact sheets support screening only, not fine callout reading. Contradictions remain recorded. Preserve recognizable canonical rooms before reconciling unseen connections; label the compromise.

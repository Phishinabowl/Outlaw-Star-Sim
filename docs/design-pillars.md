# Design pillars

1. The XGP is the main character.
2. Physical interaction matters: equipment has a location; travel and local access sometimes matter.
3. Ship systems have authoritative state; displays reflect it.
4. Systems interconnect in believable, game-manageable ways.
5. Gilliam and players operate the same simulation.
6. Depth without pointless complexity: values support gameplay, useful state, or immersion.
7. Start dormant and progress through physical entry and staged power-up.
8. Future combat constrains architecture but is not an MVP requirement.
9. One physical player supports first and third person.
10. Camera mode and control mode are separate.
11. Never silently invent canon; classify evidence and compromises.

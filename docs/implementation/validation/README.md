# Validation Procedure Ownership

The seven existing procedure documents are scoped to Vertical Slice 1's VS1 scenario IDs,
requirements and execution gates. They live under the
[slice's validation procedures](../vertical-slices/slice-01-awakening/validation/procedures/),
with their [scenario register](../vertical-slices/slice-01-awakening/vertical-slice-1-implementation-plan.md#validation-register-and-requirement-traceability).

Keep actual results under the owning slice phase/subphase, beside its closeout; the
[slice directory](../vertical-slices/slice-01-awakening/README.md) links those records. Procedure
acceptance and executed/passed scenarios remain separate statuses.

No whole procedure is currently established as shared across implementation efforts. Do not
duplicate or generalize the VS1 documents to populate a shared folder. Create a shared procedure
only after its cross-effort purpose, authority and content are explicitly scoped. Future slices
may reference relevant guidance while retaining their own requirements and acceptance evidence.

Raw traces, captures and other generated outputs retain their existing local-only ownership.
This directory is navigation, not a new test framework or permission to execute tests or editors.

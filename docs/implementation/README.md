# Implementation Efforts

Use this directory to find implementation plans and their supporting records. The
[project roadmap](../roadmap.md) owns overall project direction; each effort's plan owns its
scope, phase sequence and acceptance. This directory does not introduce a second status registry.

| Effort | Owner / navigation |
| --- | --- |
| Vertical Slice 1 — Awakening the Outlaw Star | [Slice records](vertical-slices/slice-01-awakening/README.md) and [implementation plan](vertical-slices/slice-01-awakening/vertical-slice-1-implementation-plan.md) |
| Reference and implementation documentation reorganization | [Project records](projects/reference-index-reorganization/README.md) and [reorganization plan](projects/reference-index-reorganization/reference-index-reorganization-plan.md) |
| Validation ownership | [Procedure directory](validation/README.md); slice-specific procedures stay with their slice |
| Deferred Blender Sandbox investigation | [Retained design/findings](investigations/blender-sandbox/blender-sandbox-pilot-design.md); deferred status remains in that record |

Keep a record with the slice, supporting project or investigation it serves. Put phase-specific
results beside that phase's decisions and closeout. Shared procedures need an established
cross-effort purpose and explicit ownership. Create future effort directories only when needed;
an existing directory or approved plan does not authorize execution.

Architecture, development guidance, reconstruction baselines and evidence retain their existing
owners elsewhere in `docs` and `reference`. Preserve original filenames, IDs, approval history
and evidence limits when adding navigation or moving records.

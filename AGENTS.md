# Project instructions

Read README.md and docs/canon-policy.md before project work.

- Sources _source_settei/ and _source_episodes/ are immutable and local-only. Read only.
- Never commit source media or derivative frames without explicit authorization.
- The user approves phases/subphases. Phase 0 bootstrap, documentation, full settei screening, evidence records, and tooling plans are approved. Tool installation is deferred to user discussion.
- Do not initialize Unreal, implement gameplay, model geometry, broadly extract episodes, or commit without explicit authorization.
- Separate verified observations from brief-supplied claims and reconstruction proposals. D/E/F evidence categories are never canon.
- Prefer small deterministic tools, source-relative references, and visually reviewed annotations. Flag unclear Japanese; do not guess.
